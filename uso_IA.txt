respuesta IA:

Para desarrollar el **Paso 3**, vas a crear un componente llamado `Header.jsx` dentro de la carpeta `src/components/`. Su función es ofrecer un menú de navegación que cambie de página sin recargar la web.

Aquí tienes la explicación detallada y el código paso a paso:

### 1. Ubicación del archivo

Crea el archivo en la siguiente ruta:
`src/components/Header.jsx`

---

### 2. Puntos clave a tener en cuenta

* **Importar `NavLink`:** En React Router se utiliza `NavLink` (en lugar de etiquetas HTML `<a>`) para que la navegación sea SPA (Single Page Application) sin recargar la página. Además, `NavLink` detecta automáticamente qué ruta está activa para aplicar estilos CSS.
* **Propiedad `end` en el enlace de Inicio (`/`):** Por defecto, React Router verifica si la URL actual *comienza* con la ruta del `NavLink`. Como todas las rutas empiezan con `/` (por ejemplo, `/sobre-mi`), la ruta raíz `/` siempre se consideraría "activa". La propiedad `end` le indica a React Router que solo marque el enlace de **Inicio** como activo si la URL es **exactamente** `/`.

---

### 3. Código completo de `Header.jsx`

```jsx
import { NavLink } from 'react-router-dom';

export default function Header() {
  return (
    <header>
      <nav>
        <ul>
          <li>
            {/* Se agrega 'end' para que solo se active en la ruta exacta "/" */}
            <NavLink to="/" end>
              Inicio
            </NavLink>
          </li>
          <li>
            <NavLink to="/sobre-mi">
              Sobre mí
            </NavLink>
          </li>
          <li>
            <NavLink to="/habilidades">
              Habilidades
            </NavLink>
          </li>
          <li>
            <NavLink to="/proyectos">
              Proyectos
            </NavLink>
          </li>
          <li>
            <NavLink to="/contacto">
              Contacto
            </NavLink>
          </li>
        </ul>
      </nav>
    </header>
  );
}

```

---

### ¿Cómo funciona por dentro?

Cuando este componente se renderice en pantalla, `NavLink` le añadirá automáticamente la clase CSS `.active` al enlace de la página en la que te encuentres. Si deseas agregarle estilos CSS más adelante, podrás destacar el enlace activo simplemente apuntando a esa clase en tu archivo de estilos:

```css
/* Ejemplo de CSS */
nav a.active {
  font-weight: bold;
  color: #0070f3;
}

```
